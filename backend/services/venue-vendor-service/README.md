# Venue & Vendor Service

Node.js + Express + MongoDB microservice for EventZen venue and vendor management.

## Scope Implemented

- Venue CRUD (create + list), hall support, amenities, media gallery
- Real-time slot availability with booking conflict detection
- Venue booking endpoint for ADMIN/ORGANIZER
- Vendor catalog with service category filters
- Vendor onboarding endpoint for ADMIN
- Event-vendor contract creation and lifecycle status transitions
- Vendor review and rating aggregation
- JWT auth/RBAC compatible with `auth-service` access tokens

## PRD/System Design Endpoint Coverage

- `POST /api/v1/venues`
- `GET /api/v1/venues`
- `GET /api/v1/venues/:id`

- `DELETE /api/v1/venues/:id`

- `POST /api/v1/venues/:id/book`
- `GET /api/v1/vendors`

- `POST /api/v1/events/:id/vendors`
- `PATCH /api/v1/contracts/:id/status`
- `POST /api/v1/vendors/:id/reviews`

### Auth Notes

- Service verifies Bearer JWT using `AUTH_JWT_SECRET` and `AUTH_JWT_ISSUER`.
- Expected roles come from `authorities` claim generated by `auth-service` (`ROLE_ADMIN`, `ROLE_ORGANIZER`, etc.).
- In `development`, you can bypass token checks using headers:
  - `x-user-id`
  - `x-user-roles` (comma-separated, e.g. `ADMIN,ORGANIZER`)
