Sample JSON drafts for the vendor event-import flow.

Files:
- `finops-summit-request.json`
- `ai-governance-workshop-request.json`
- `creator-economy-festival-request.json`

These are ready to upload from the vendor event request drawer.

Notes:
- Categories match seeded IDs and names in `event-service`.
- Venues match seeded IDs and names in `venue-vendor-service`.
- The importer accepts either IDs or names for category and venue.
- After import, the vendor can still edit every field before submitting.
