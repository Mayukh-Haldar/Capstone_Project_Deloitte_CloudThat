Sample JSON drafts for event import flows.

- `admin-public-sector-innovation-summit.json`

Vendor files are ready to upload from the vendor event request drawer.

Admin files are ready to upload when creating events from the admin portal.

Notes:
- Categories match seeded IDs and names in `event-service`.
- Venues match seeded IDs and names in `venue-vendor-service`.
- The importer accepts either IDs or names for category and venue.
- After import, the user can still edit every field before submitting or creating the event.
